─── 1. Локально (3 термінали) ───────────────────────────────────────────────

# Термінал 1 — Backend
source .venv/bin/activate
cd backend
PYTHONPATH=. alembic upgrade head   # один раз після git pull, якщо «no such table»
PYTHONPATH=. python3 -m uvicorn app.main:app --reload --host 0.0.0.0 --port 8000

# Термінал 2 — Telegram-бот (привʼязка акаунта, сповіщення)
source .venv/bin/activate
cd bot
python main.py

# Термінал 3 — Frontend
cd frontend
npm run dev

  Frontend   http://localhost:3000
  API docs   http://localhost:8000/api/docs
  Admin      http://localhost:3000/admin  (admin / admin123 за замовч.)

─── 2. Новий функціонал (коротко) ───────────────────────────────────────────

▸ Вхід / реєстрація — ТІЛЬКИ номер телефону
  • Реєстрація → SMS-код (TurboSMS, відправник Carbit)
  • Вхід → код у Telegram, якщо акаунт привʼязаний до бота
  • Якщо Telegram недоступний → SMS (кнопка «Надіслати SMS»)
  • Повторна відправка коду — не частіше 1 раз на хвилину
  • Email / Google / вхід через бота на сторінці login — вимкнено в UI

▸ Голосовий пошук (AI)
  • Тільки в кабінеті: /app/search, /app/dashboard
  • На лендінгу кнопка «Голосом» показує підказку «доступно в кабінеті»
  • Потрібен OPENAI_API_KEY у .env
  • Запис зупиняється після 5 сек тиші → AI заповнює фільтри → «Шукати»

▸ Порівняння без входу
  • /app/compare?ids=olx_... — працює для гостей

▸ Telegram у кабінеті
  • Налаштування → привʼязати Telegram (сповіщення + коди входу)
  • Бот: TELEGRAM_BOT_TOKEN + TELEGRAM_BOT_USERNAME у .env

▸ Публічне порівняння / Instagram / інше
  • Див. git log і frontend/src/components/social/

─── 3. .env — обовʼязкові змінні для нових фіч ───────────────────────────────

# ── TurboSMS (реєстрація + SMS-fallback при вході) ──
turbo_sms_token=...          # або TURBOSMS_TOKEN=...
TURBOSMS_SENDER=Carbit       # має бути АКТИВОВАНИЙ у кабінеті turbosms.ua
                             # помилка NOT_ALLOWED_MESSAGE_SENDER = sender не схвалений

# ── OpenAI (голосовий пошук у кабінеті) ──
OPENAI_API_KEY=sk-...

# ── Telegram-бот ──
TELEGRAM_BOT_TOKEN=...
TELEGRAM_BOT_USERNAME=Car_Bit_Bot
INTERNAL_API_SECRET=...      # однаковий у backend і bot

# ── Загальне ──
FRONTEND_URL=http://localhost:3000
NEXT_PUBLIC_API_URL=/api/v1
DEBUG=true                   # локально; на проді DEBUG=false

# KV / сесії (локально SQLite, без окремого Redis)
REDIS_URL=sqlite://database/kv.db

─── 3. .env на production ────────────────────────────────────────────────────

FRONTEND_URL=https://carbit.info
NEXT_PUBLIC_API_URL=/api/v1
DEBUG=false
SECRET_KEY=...               # python3 -c "import secrets; print(secrets.token_urlsafe(32))"

# Auth / SMS
TURBOSMS_TOKEN=...
TURBOSMS_SENDER=Carbit

# Голосовий пошук
OPENAI_API_KEY=...

# Telegram
TELEGRAM_BOT_TOKEN=...
TELEGRAM_BOT_USERNAME=Car_Bit_Bot
INTERNAL_API_SECRET=...

# OAuth (legacy API, UI вимкнено — можна лишити для старих акаунтів)
GOOGLE_CLIENT_ID=...
GOOGLE_CLIENT_SECRET=...
GOOGLE_REDIRECT_URI=https://carbit.info/api/v1/auth/google/callback

# Email (Resend — привʼязка email у кабінеті, не для login)
RESEND_API_KEY=...

# Telegram parser
TELEGRAM_ENABLED=true
TELETHON_API_ID=...
TELETHON_API_HASH=...
TELETHON_NUMBER=+380...
TELETHON_SESSION_NAME=carbit_parser
# Канали — в адмінці /admin/channels

Важливо:
• NEXT_PUBLIC_API_URL — build-time для frontend → після зміни rebuild frontend
• BACKEND_URL для browser — публічний URL; bot/worker у Docker отримують backend:8000 з compose
• НЕ використовуй http://backend:8000 у NEXT_PUBLIC_API_URL

─── 11. Типові проблеми ──────────────────────────────────────────────────────

| Симптом                              | Рішення                                           |
|--------------------------------------|---------------------------------------------------|
| NOT_ALLOWED_MESSAGE_SENDER           | Активуй sender «Carbit» у turbosms.ua             |
| 401 після реєстрації / входу         | Перезапусти backend; kv.db має підтримку zadd   |
| SMS не приходить                     | TURBOSMS_TOKEN, баланс TurboSMS, sender активний  |
| Код входу не в Telegram              | Привʼязати Telegram у кабінеті; fallback — SMS   |
| Голосовий пошук не працює            | OPENAI_API_KEY; тільки в /app, не на лендінгу     |
| telegram-worker AuthKeyDuplicated    | Один .session на VPS; /admin/channels → скинути   |
| 0 оголошень Telegram                 | Канали в /admin/channels, TELEGRAM_ENABLED=true   |
| Старий UI                            | rebuild frontend + hard refresh                   |
| no such table                        | alembic upgrade head (локально або в Docker logs) |


─── 12. Telethon-сесія ───────────────────────────────────────────────────────

Файл: database/<TELETHON_SESSION_NAME>.session

Адмінка: /admin/channels → Telethon → скинути → код → up telegram-worker

CLI на VPS:
  docker compose stop telegram-worker
  docker compose run --rm -it -w /app --entrypoint python telegram-worker auth.py --reset
  docker compose up -d telegram-worker
